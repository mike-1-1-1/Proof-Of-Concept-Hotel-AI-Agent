# Proof-Of-Concept-Hotel-AI-Agent
A proof of concept of an AI Hotel Assistant that handles various guest queries in a professional but friendly manner. This agent is built on top of Microsoft Foundry (https://azure.microsoft.com/en-us/products/ai-foundry) as part of my completion of certification course called AI agent fundamentals with Azure AI Foundry.
